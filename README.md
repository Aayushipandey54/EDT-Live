# EDT World

Vite + React redesign of [edtworld.com](https://edtworld.com/) — Origin Orange brand preserved, UX updated for premium storytelling, discovery, trust, and demo checkout.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Routes

- `/` Home
- `/shop` Catalog + filters
- `/product/:slug` Product detail
- `/checkout` Demo multi-step checkout
- `/combos` `/recipes` `/gifting` `/contact` `/store-locator` `/news`
